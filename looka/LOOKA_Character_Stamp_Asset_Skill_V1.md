# LOOKA Character Stamp Asset Generation Skill V1

## Purpose

用于生成 LOOKA 日历/手帐 App
的角色印章（Stamp）资产。目标不是单张插画，而是可长期复用的产品级角色资产。

------------------------------------------------------------------------

# 1. 输出画布标准

## Master Sheet（设计审核图）

-   尺寸：2048 × 1536 px
-   比例：4:3
-   背景：纯白或透明灰白
-   不允许出现卡片边框、圆角格子、展示框
-   不添加标题、文字、编号、标签
-   只展示图标本身

布局：

-   6列 × 4行
-   共24个图标
-   图标之间保持均匀间距
-   不裁切角色
-   不允许任何元素超出安全区域

------------------------------------------------------------------------

# 2. 单个 Stamp 输出标准

每个独立图标：

-   PNG
-   256 × 256 px
-   RGBA透明背景
-   无边框
-   无底色
-   无阴影背景板
-   无文字

安全区域：

-   主体占画布 70%～85%
-   四周至少保留 15%透明空间
-   视觉中心略偏上

------------------------------------------------------------------------

# 3. 截图/切图规则

从 Master Sheet 提取：

-   不根据视觉猜测裁剪
-   使用固定网格切割
-   每个格子必须尺寸一致

推荐：

Master Sheet: 2048×1536

切割：

列： 6

行： 4

每格：

341×384 px

然后：

自动去除透明/白色背景

缩放到：

256×256 px

------------------------------------------------------------------------

# 4. 角色一致性要求

同一角色必须保持：

-   身体比例一致
-   毛色一致
-   五官一致
-   牛角形状一致
-   鼻子颜色一致
-   光影方向一致

禁止：

-   每张图重新设计角色
-   改变年龄感
-   改变脸型
-   改变IP识别特征

------------------------------------------------------------------------

# 5. 图层规划

最终资产建议：

character/ - cow_happy.png - cow_sleepy.png

decoration/ - sparkle.png - heart.png - music_note.png

metadata/ - stamps.json

角色和装饰必须可以独立复用。

------------------------------------------------------------------------

# 6. 风格规范

LOOKA 风格：

-   日式手帐
-   温暖
-   克制
-   治愈
-   可爱但不过度幼儿化

视觉：

-   柔和3D插画
-   干净轮廓
-   轻微立体感
-   柔软材质

避免：

-   强烈游戏UI感
-   复杂背景
-   过度阴影
-   过多装饰

------------------------------------------------------------------------

# 7. 生成提示词要求

生成前必须明确：

1.  角色身份
2.  角色固定外观
3.  动作列表
4.  输出尺寸
5.  切图规则
6.  禁止边框和文字

------------------------------------------------------------------------

# 8. 产品级检查

生成完成后检查：

□ 是否24个完整图标\
□ 是否没有边框\
□ 是否没有文字\
□ 是否透明背景\
□ 是否256×256\
□ 是否角色比例统一\
□ 是否可以直接进入App资源库\
□ 是否支持未来动画和3D扩展
