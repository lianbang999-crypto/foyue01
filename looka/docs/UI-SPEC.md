# Looka UI 冻结规格 v1.3（对齐 Lifebear 视觉语言，独立原创实现）

> 独立项目约定：不参考本团队以前任何项目的风格与设计系统，仅对齐 Lifebear 的产品语言。

## 品牌
- 可爱版九色鹿：白鹿 + 九色光环（敦煌九色鹿意象），品牌绿 `#55B04B` 固定

## 全局
- 背景纯白；分隔线 0.6dp `#ECECEC`；主文字 `#1B1B1F`；次级 `#8A8F8E`
- 顶栏 52dp：左返回 / 左对齐标题 17-18sp SemiBold / 右操作；保存=深色 `#3F3F46` 圆角 8dp 按钮
- 选中态：黑色实心圆/下划线；链接蓝 `#2E6BD8`；休日红 `#E0504A`；周六蓝 `#4A7DDC`
- 底栏 58dp：四 Tab + 中央黑色 48dp 圆形 ＋（上浮 8dp）

## 月视图
- 星期头 11sp；格子日号 11sp（今天=主题色圆、选中=黑圆白字）
- 格内条目 8sp、最多 3 行：全天=实底色块(圆角2)、时间=分类色文字、系统日历=◦前缀色字、任务=✓灰字；溢出 `+n`
- 选中日面板 200dp：日期头 14sp + 条目行（3dp 色条 / 34dp 高）

## 周/日时间轴（像素冻结）
- 小时高 **60dp**；左时间栏 **46dp**，时间 9sp 贴线右对齐
- 今日列底色 = 主题浅底 35%；列左界线 1.6px
- 日程块：圆角 6dp、白色 1dp 分隔描边、最小高 26 分钟、标题 10sp/时间 8sp
- 系统日历块：描边样式（1dp 色边 + 10% 色底 + 色字），与自有日程实底区分
- 当前时间：红 1.5dp 横线 + 左端 6dp 圆点；长按创建吸附 30 分钟

## 动效（全局 140–220ms，低装饰原则）
- 月份切换：AnimatedContent 方向滑动 220ms + 淡入
- 页面转场：进入右滑 1/5 屏 + 淡入 200ms；返回反向
- 「显示详细设置」：expandVertically + fade
- 待办勾选：图标 1.35→1.0 弹簧（MediumBouncy）；列表 animateItem 位移
- 空状态小鹿：±5dp 1.6s 往复浮动
- 网页端同参数（CSS transition/keyframes 对应实现）

# 新增功能全生命周期规则（v1.2 新增）

> 本节是全站强制门禁。新增功能不再以“页面已经做出来”作为完成标准，而要同时具备发现、启用、使用、退出、停用、移除、删除数据、恢复和退场的完整通道。

## 1. 全局准入：先判断是否应该增加

每项新功能立项前必须回答以下问题；任一项没有答案，不进入页面设计：

1. 它解决的是高频核心问题、低频管理问题，还是可选增值问题？
2. 它应进入现有哪个产品域，能否复用当前入口，而不是新增一级导航？
3. 默认开启是否会增加认知负担、权限、通知、网络、存储或付费风险？
4. Free、Pro、Founder、鹿角与地区规则分别是什么？
5. Android、网页及未来商店版不能等价实现时，替代路径是什么？
6. 用户不用它时，如何关闭；不再需要时，如何移除；数据如何导出和删除？
7. 功能失败、离线、权限拒绝、订阅到期、退款和服务退场时，用户如何回到安全状态？

**准入原则**：核心功能优先接入现有场景；低频功能进入设置或更多；可选能力采用渐进披露；实验能力默认关闭。不能因为“已经开发”就获得首页入口。

## 2. 功能生命周期合同

每个 Feature 必须建立一份 `feature.lifecycle.v1` 合同，至少登记：

| 阶段 | 必须定义 | 验收问题 |
|---|---|---|
| 发现 | 场景入口、搜索/帮助入口、适用对象 | 用户为什么会在这里看到它？ |
| 预览 | 一句话价值、真实能力、费用与权限 | 不启用也能理解，不提前承诺未来能力 |
| 启用 | 登录、资格、权限、下载、付费条件 | 取消后是否原地返回？是否重复请求权限？ |
| 首次使用 | 最小示例、默认值、跳过 | 不强迫完成教学，不遮挡手工路径 |
| 日常使用 | 主任务、保存边界、错误、离线 | 一屏一个主要动作，状态可恢复 |
| 暂停/关闭 | 开关位置、影响范围、数据保留 | 关闭只停止能力，不偷偷删除数据 |
| 移除/卸载 | 入口、组件/缓存处理、关联对象 | 移除后核心内容仍可读取和导出 |
| 删除数据 | 本机、云端、AI 派生、缓存范围 | 明确说明不可逆部分，并提供导出 |
| 恢复 | 重新启用、重新下载、恢复购买、恢复默认 | 不重复收费，不制造重复数据 |
| 退场 | 替代方案、通知、导出、兼容期 | 先建立出口，再移除旧入口 |

## 3. “关闭、移除、删除、注销”必须分开

- **关闭功能**：停止运行、提醒或读取权限；保留内容与设置，可随时重新开启。
- **移除功能**：隐藏入口并清理可重新下载的组件和缓存；用户创建的数据默认保留，不与“删除数据”捆绑。
- **删除该功能的数据**：单独的危险操作，逐项说明本机、云端、附件、AI 记忆和派生数据；删除前允许导出。
- **恢复默认设置**：只重置偏好，不删除内容、账号、订单或永久权益。
- **退出登录**：只结束本机账号会话，不等于删除云端数据。
- **注销账号**：账号级流程，必须列出数据、订阅、Founder/永久权益与恢复期后果。

禁止使用一个模糊的“删除/卸载”按钮同时完成上述多种动作。

## 4. 删除与恢复的 UI/UX 规则

- 普通可逆内容：就地删除，提供短时“撤销”；必要时进入回收站。
- 功能关闭：使用设置行开关或“关闭功能”，不弹夸张警告；下方一句说明保留什么。
- 功能移除：使用普通确认页或底部页，主要动作是“移除”，危险的“同时删除数据”不得默认勾选。
- 永久删除：使用独立危险确认；写明对象、数量、设备/云端范围、是否影响共享对象和能否恢复。
- 订阅到期或退款：停止新增的 Pro 能力，不删除用户已经创建的日程、任务、笔记、日记和可保留成果。
- 重新启用：恢复原入口、原设置和可用数据；购买型功能先执行账号级权益恢复，不要求用户再次付款。

所有确认层遵守 Lifebear 式克制结构：小圆角、白底、短标题、两至三行说明、一个主动作和一个取消动作；不使用大插画、倒计时、连续挽留或多层弹窗。

## 5. 信息架构与视觉接入

- 不为单一新功能增加一级 Tab；先放进现有日历、待办、笔记、更多、小鹿或设置域。
- 设置页只承担稳定偏好和关闭/恢复；购买进入方案页；内容发现进入商店；报错进入帮助与反馈。
- 默认页面使用留白、分隔线和普通行，不把每个生命周期状态做成大圆角卡片。
- 启用、停用、删除和恢复使用同一术语、组件与动效 Token；状态变化为 160–220ms，无弹跳、无庆祝。
- 同一个功能只能有一个管理页。其他入口只显示摘要并跳转，禁止复制一套开关。

## 6. 功能退场规则

产品删除某项功能时，顺序必须是：

1. 冻结新入口与新购买；
2. 提供替代路径、导出和数据说明；
3. 保留旧数据只读和权益恢复；
4. 完成 Android、网页、服务端、合同、帮助和本地化清理；
5. 验证没有孤儿路由、失效深链、残留通知、后台任务和重复扣费；
6. 最后才删除实现与历史入口。

只删除按钮但保留后台任务，或只删除代码但让用户数据无法读取，均视为未完成。

## 7. 新功能 Definition of Done 补充

除原有双端、状态、无障碍和真机要求外，每项新功能还必须通过：

- [ ] 唯一入口、返回和深链已登记；
- [ ] 启用、跳过、权限拒绝和首用链路完整；
- [ ] 关闭、移除、删除数据和恢复四种语义已区分；
- [ ] 订阅到期、退款、离线和服务不可用时不丢核心数据；
- [ ] 后台任务、通知、缓存、权限和云端派生数据有清理规则；
- [ ] App 与网页的差异及替代路径已记录；
- [ ] 功能退场时有导出、兼容和旧入口移除方案；
- [ ] 至少完成一次“启用到移除，再恢复”的真机闭环测试。

# Paddle 支付接入全局规则（2026-08-27 调研基线）

> Paddle 作为 Merchant of Record，可负责全球 Web 收款、税务、发票、退款和订阅生命周期；但它不是所有平台、所有支付方式和所有低价 SKU 的无条件唯一通道。

## 1. 渠道边界

| 场景 | 建议通道 | 关键限制 |
|---|---|---|
| Web / PWA | Paddle Checkout | 作为首选全球通道 |
| 官网下载 Android APK | Paddle Checkout | 可在网页完成购买，账号恢复权益 |
| Google Play 版 | Google Play Billing 为默认 | 只有符合地区与项目规则时才显示 Paddle 外链 |
| 未来 iOS App Store 版 | StoreKit IAP 为默认 | 外部购买链接按 storefront 和 entitlement 单独判断 |
| 中国支付宝 | Paddle Alipay | 需 Paddle 额外审批；CNY；支持一次性与订阅 |
| 中国微信支付 | Paddle WeChat Pay | 仅桌面 Checkout、CNY/USD、一次性购买；不支持订阅 |

因此，“支付宝/微信都支持”是支付方式层面的事实，但不能推导为“微信可以支付 Looka Pro 月费自动续订”。

## 2. 经济可行性门禁

Paddle 当前公开标准费率为每笔 `5% + US$0.50`。对 Looka 现行低价方案，固定费用占比很高：

| SKU | 标准费率下的约费用占比 | 处置 |
|---|---:|---|
| US$5 月付 | 约 15% | 海外 Pro 月付正式基准；仍申请低价交易报价 |
| US$50 年付 | 约 6% | 海外 Pro 年付正式基准；相对月付省约 17% |
| ¥12 月付 | 固定 US$0.50 已显著侵蚀收入 | 先谈低价报价；否则保留其他国内月付通道 |
| ¥19.9 Founder 买断 | 仍偏高，但可限量试点 | 与年付一起验证真实成功率和退款成本 |
| ¥6 鹿角包 | 不适合标准费率 | Paddle 首发最低从 ¥18 或更高组合包开始 |

Paddle 官方也要求低于 US$10 的产品联系其团队讨论定价。未取得书面费率前，不把 Paddle 写成所有低价商品的唯一渠道。

## 3. 单一权益解析，不让支付渠道污染产品

全站只维护一个 `EntitlementResolver`。Paddle、Google Play、未来 StoreKit、Founder 赠送、兑换码和旧渠道订单都只产生标准化权益事件：

`provider + external_order_id + account_id + sku_id + status + effective_at + expires_at + refund_state`

页面只读取最终权益，不自行判断“Paddle 用户”“微信用户”或“Ko-fi 用户”。同一账号跨网页和 App 自动恢复；切换渠道不得生成第二份 Pro。

## 4. Paddle 完整支付闭环

方案页选择真实 SKU → 服务端创建 Checkout/Transaction → Paddle 托管结账 → 页面进入“正在确认” → 服务端验签并接收 Webhook → 以 `transaction.completed`/订阅事件幂等记账 → 发放 Pro 或鹿角 → 客户端刷新权益 → 显示收据与管理入口。

必须覆盖：支付取消、延迟捕获、重复 Webhook、支付成功但客户端关闭、续费失败、暂停、升级/降级、取消续费、退款、拒付、恢复购买和账号不匹配。

微信支付属于延迟捕获，不能以 Paddle.js 的前端 `checkout.completed` 直接发货；必须等待服务端可信事件并保持“正在确认”状态。

## 4.1 App 外跳官网支付定案

当前官网下载版 Android App 不在 App 内嵌支付表单。用户点击“升级 Pro”后，使用系统浏览器或 Android Custom Tab 打开：

`https://looka.foyue.org/pay?session={short_lived_signed_session}`

完整链路：App 请求短期支付会话 → 打开 `/pay` → 页面按账号、地区和资格展示唯一可购方案 → Paddle Checkout → `/pay/success` 显示“正在确认”与“返回 Looka” → 服务端接收可信 Webhook 幂等发放权益 → App 恢复时重新读取 `EntitlementResolver`。

- 不使用 App 内 WebView 承载 Paddle、钱包、3DS 或银行验证。
- URL 不传邮箱、价格、Price ID、方案资格或可伪造的账号字段，只传短期签名会话。
- `/pay` 只负责展示与结账；不能以前端 `checkout.completed` 直接开通。
- App 返回后允许保持“正在确认”，支持关闭页面、网络中断和稍后恢复。
- “管理订阅”进入 Paddle Customer Portal，不回到购买入口。
- Google Play 与未来 iOS 商店版使用独立发行渠道规则；不把官网外跳当作所有商店版本的默认实现。

## 4.2 海外 Pro 定价定案

| 市场 | 月付 | 年付 | 年付心智 |
|---|---:|---:|---|
| 中国大陆基准 | ¥12 | ¥98 | 相对月付省约 32% |
| 海外 USD 基准 | US$5 | US$50 | 相对月付省约 17%，约等于赠送 2 个月 |

价格按账单国家、可用币种和支付渠道解析，不按界面语言判断。海外页面使用简洁整数 `$5 / month`、`$50 / year`；税费、续费时间和退款规则以 Paddle Checkout 的真实结果为准。

## 5. 订阅与删除闭环

- 方案页必须提供“管理订阅”，进入 Paddle Customer Portal 或对应商店管理页。
- “取消续费”说明当前权益保留到何时；不能写成“立即失效”，除非真实合同如此。
- 删除账号前检查有效订阅，先引导取消；不能假定删除 Looka 账号会自动停止 Paddle 扣费。
- 退款/拒付由权益事件回收未继续享有的服务，但用户原始内容不删除。
- 解绑支付资料、删除功能数据、注销 Looka 账号和取消订阅必须是四条独立链路。

## 6. 分阶段接入建议

1. 完成 Paddle 账户、身份与 `looka.foyue.org` 域名审核；申请 Alipay 和低于 US$10 的自定义费率。
2. 在 Sandbox 建立 Founder、海外 US$5 月付、US$50 年付、国内方案与鹿角包 SKU；先验证年付和 Founder。
3. 服务端实现验签、幂等、权益解析、退款/取消和对账；密钥只在服务端。
4. 网页与官网 APK 先灰度；旧爱发电/Ko-fi 不立即删除，先作为已购用户恢复与短期回退。
