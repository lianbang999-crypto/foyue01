# Looka 网页版使用指南

> 适用范围：当前 Looka 网页版（`looka.foyue.org`）  
> 核对日期：2026-08-24  
> 本文按当前网页的实际功能编写；后续界面更新时，按钮位置或名称可能略有变化。

Looka 是一款把日历、待办、笔记、日记和小鹿 AI 放在一起的生活手帐。本文先帮助你快速完成常见任务，再逐项说明网页上的按钮。

## 一分钟上手

### 新建日程

1. 打开底部的“日历”。
2. 点选日期。
3. 点击日期详情中的“＋ 日程”，或直接点击底部中央的“＋”。
4. 填写日程名、日期和时间。
5. 点击“保存”。

### 添加待办

1. 打开底部的“待办”。
2. 在“添加任务……”中输入内容。
3. 按回车，或点击右侧“＋”。

### 写笔记

1. 打开底部的“笔记”。
2. 点击“＋ 新建”，或点击底部中央的“＋”。
3. 填写标题和正文后点击“保存”。

### 写今天的日记

1. 打开“更多”。
2. 点击“日记”。
3. 点击“写今天”。
4. 选择心情、填写内容并保存。

### 让小鹿 AI 帮你记录

1. 打开“更多” → “小鹿 AI”。
2. 输入自然语言，例如“明天下午 3 点开会”。
3. 点击发送箭头。
4. 如果小鹿提出新增、修改或删除操作，请先检查操作清单，再点击执行。

## 使用前先了解

- 网页登录后，日程、待办、笔记和日记会自动同步；也可以手动点击“立即同步”。
- 小鹿 AI 每次对话消耗 1 枚鹿角。免费用户每天获得 10 枚，Pro 用户每天获得 50 枚。
- “删除”“清理重复日程”和“导入恢复”可能改变已有数据，操作前请仔细查看提示。
- 建议定期用“导出数据”保存一份 JSON 备份，尤其是在导入其他备份之前。
- 网页端修改重复日程时，会修改整个重复系列。只修改其中一次，请使用支持该功能的 App 版本。

### 中央“＋”会做什么

中央“＋”会根据当前页面改变作用：

- 在“日历”或“更多”页面：新建日程。
- 在“待办”页面：把光标放到“添加任务……”输入框。
- 在“笔记”页面：新建笔记。
- 在“日记”页面：写今天的日记。

### 删除重复日程时的范围

- “仅本次”：只删除当前这一次。
- “本次及以后”：删除本次和之后的同系列日程。
- “全部”：删除整个重复系列。

注意：当前网页端编辑重复日程时，修改的是整个系列；上面的范围选项主要用于删除。

## 数据、同步与备份

### 自动同步

登录后，Looka 会在修改数据后安排同步，也会定时同步，并在页面重新获得焦点时检查更新。网络不稳定时，请等网络恢复后再点击“立即同步”。

### 手动同步

可以从两个位置操作：

- 顶部账号按钮 → “立即同步”。
- “更多” → “立即同步”。

### 导出数据

“导出数据”会下载一个 `looka-export-日期.json` 文件。请把它保存在自己能找到的位置，不要手动修改内容。

### 导入恢复

导入会合并或覆盖记录，并立即准备同步到账号；它不是把整个账号完全还原到某个历史时间点。主题、语言等设置不会被导入。

为避免误操作，建议按以下顺序进行：

1. 先点击“导出数据”，保存当前备份。
2. 再点击“导入恢复”，选择需要导入的 Looka JSON 文件。
3. 导入完成后检查几条日程、任务、笔记和日记。
4. 确认无误后点击“立即同步”。

## 常见问题

### 为什么点击中央“＋”后没有打开新建窗口？

在“待办”页面，中央“＋”的作用是把光标移到任务输入框；输入任务后按回车或点输入框右侧的“＋”。

### 为什么修改一次重复日程，其他日期也变了？

当前网页版会把重复日程作为整个系列修改。只想修改其中一次时，请使用支持单次编辑的 App 版本。

### 删除表情会不会删除日程？

如果该表情已经绑定日程，当前版本会同时删除表情和日程。删除前的确认弹窗会显示日程名称，请务必核对。

### 付款后为什么还没有显示 Pro？

付款后切回 Looka，稍等片刻让网页刷新账号状态。如果仍未开通，可在“更多”中使用“我已付款，认领订单”，粘贴完整的爱发电订单号。

### 导入会不会覆盖现有内容？

会合并数据；UID 相同的记录会被导入文件中的版本覆盖。因此导入前一定要先导出当前数据。

### 退出登录会删除数据吗？

不会。退出登录只会移除当前浏览器的登录状态，不会删除云端账号或云端数据。

### 如何联系支持？

请发送邮件至 `looka01@qq.com`，并尽量说明使用设备、浏览器、发生时间和看到的提示。
