# Looka 小鹿 AI 行为与界面规格 v1.0

> 2026-08-27 · 依《全站UIUX统一规划》G1 预留位建立,是小鹿的行为宪法。
> 地位:小鹿的每一处功能与界面改动对着本文验收;与本文冲突的实现视为缺陷。
> 现状标记:✅ 已上线 · 🔜 已排期 · 💡 方向(未排期不得写进用户可见文案)

---

## 0. 北极星:什么叫优秀的 AI(对手帐产品而言)

不是聊天最强。三条可度量的标准:

1. **少一步**——同一件事经过小鹿比手工少几次点击/少打几个字,达不到就不该走 AI。
2. **看得懂**——小鹿开口前已知道用户在哪天、哪个清单、哪篇笔记;上下文是带进来的,不是问出来的。
3. **信得过**——它说的每条安排都能在数据库指出来源;它做的每次修改都先给用户看、都能撤销。

源头原则(LOOKA-OX):**AI 的最高原则是降低输入成本和理解成本,而不是增加一个 AI 模块。**
衡量小鹿只看这三条,不看对话流畅度。

## 1. 五层架构

| 层 | 职责 | 现状 | 下一步 |
|---|---|---|---|
| L1 通道 | 模型路由与降级 | ✅ OpenRouter;文本 Qwen3.6-plus→MiniMax-M3→free;视觉 qwen3.5-flash 独立路由 | 🔜 换模型必须过评测集(§6) |
| L2 动作 | AI 的手:结构化动作协议 | ✅ AiActions(增删改×日程/任务/笔记+记忆+提醒语义) | 🔜 固化 contracts/ai-actions.v1.json 进对账门禁 |
| L3 上下文 | AI 的眼:真值注入 | ✅ agendaContext 注入近期数据;场景入口带日期 | 🔜 按需检索(问什么取什么);授权矩阵维持:日记正文永远默认关 |
| L4 记忆 | AI 的心:跨会话事实 | ✅ deerFacts 可看可逐条删(小鹿设置) | 🔜 确认式沉淀(§5.5);💡 结构化记忆(作息/常用人) |
| L5 交付 | AI 的嘴:草稿与确认 | ✅ 草稿确认卡(删除必确认/≥3必确认/逐条勾)、撤销 | 🔜 diff 预览行;结果态卡 |

**铁律:永不给 AI 开数据后门。** AI 执行动作调用与手工操作完全相同的 ViewModel/DAO 方法——
同一套校验、同一套同步、同一套撤销。

## 2. 服务矩阵(三任务)

| 任务 | ✅ 已上线 | 🔜 排期 | 💡 方向 | 明确不做 |
|---|---|---|---|---|
| 记录 | 一句话建日程/任务(含提醒)、识图(3🦌) | 系统分享目标、文件解析 | 语音一句话 | 长文写作工具 |
| 安排 | 今天/明天问答、拆解规划 | 冲突检测 | 时间建议 | 自动改动(建议永远是草稿) |
| 回看 | 周总结 | 月度回顾 | 去年今天、日记情绪脉络(单独授权) | 社交分享默认开 |

产品边界:小鹿不定位通用闲聊(能聊,但入口/文案/评测全围绕手帐);
**永不主动弹出**——不打断输入/拖动/删除,建议只在用户召唤时出现。克制本身是功能。

## 3. 数据准确性:七道防线

**读得准:**
1. ✅ 上下文只来自 Room 真值;提示词约束"没有的就说没有"
2. ✅ 定位键纪律:改/删只认上下文标注的 id,绝不按标题猜
3. 🔜 按需检索:检索面贴合问题,幻觉空间越小

**写得对:**
4. ✅ 草稿-确认-提交(删除必确认、批量逐条勾)
5. ✅ 与手工同一条数据通路(见 §1 铁律)
6. ✅ softDelete 5 秒撤销
7. 🔜 **评测集门禁**:30-50 条固定用例(时间解析/多动作拆解/修改定位/边界拒答/上下文忠实),
   换模型、改提示词必须跑分达标才上线。把模型质量从感觉变成数字。

时间幻觉的最后防线在 UI:草稿卡**永远显示解析后的绝对日期**,用户的眼睛做终审。

## 4. 界面设计

总口诀:**骨架全部继承(白底/细线/灰阶/小圆角/44dp/三层字号),温度只从小鹿一个形象出。**
不允许"AI 感":无紫色渐变、无科技光效、无机器人图标、无星光粒子。

### 4.1 对话页(全局入口)

```
顶栏:← | 小鹿 | 清空(锚定菜单)     52dp 白底 Hairline
消息流(LazyColumn)
快捷 chip 行(三模式:记一件事/安排/回看)
输入栏:[图 44dp] [输入框 灰底8dp圆角] [发送]
```

- 空态 = 教学页:DeerBadge 48dp + 一句自我介绍 + 三张任务行(点击填示例入输入框);用过一次永不再教
- 气泡:用户右对齐浅灰底 12dp 圆角;小鹿**左对齐无底色**(字写在纸上),前置 20dp DeerBadge 头像
- 字号三层封顶:正文 15sp / 辅助 12sp / 时间 11sp
- 发送键灰→Ink 黑,不用主题色实心

### 4.2 草稿卡(ProposalCard)——AI 的脸面

白底 0.8dp #E2E5E2 边、6dp 圆角,嵌在消息流:

```
小鹿准备做 2 件事,确认后我再动手          13sp 灰
──────────────────────────
☑ 📅 8月28日(五) 15:00  开会            日期 SemiBold
     ⏰ 提前 30 分钟提醒                 12sp 灰
☑ ✓  8月28日  买投影转接头
──────────────────────────
              [取消]  [执行勾选的 2 件]
```

硬规则:
1. 日期时间永远显示**解析后的绝对值**并加粗(终审防线)
2. 勾选框 44dp 热区;默认全勾;**删除类默认不勾**且行文字红
3. 修改类用 diff 行:`开会 15:00 → 16:00`(旧值删除线灰、新值黑)
4. 执行后卡片原地变**结果态**:绿色完成点 + 「打开」链接 + 5 秒撤销条;不消失、不弹庆祝

### 4.3 场景入口——统一"一行",不做浮球

```
🦌 问问这天的安排        ✅ 日历日面板
🦌 帮我把这个清单理一理    🔜 清单详情
🦌 帮我润色/整理成任务     🔜 笔记编辑器
```

浮动 AI 球是明确反例(遮内容、抢中央+锚点)。每行带足上下文进对话页,第一条消息填好等发送。

### 4.4 状态系统

| 状态 | 形态 |
|---|---|
| 思考中 | 小鹿头像+DeerLoading 呼吸,无文字;>3s 补「小鹿在想…」12sp 灰 |
| 流式输出 | 文字直接生长;无打字机光标、无音效 |
| 识图中 | 同上,文案「小鹿在看图…」 |
| 线路降级 | 回复尾 11sp 灰「本次走了备用线路」 |
| 失败 | 红字 13sp + 内联「重试」(失败不扣鹿角) |
| 鹿角不足 | 输入栏上方内联条(保底次数+明天规则),不弹窗、可关 |
| 余额将尽 | 仅发送前一次 11sp 提示,不常驻 |

### 4.5 记忆沉淀——一次询问一行卡

小鹿察觉稳定偏好时,回复尾部内联(不弹窗不打断):
`💭 要我记住「周一上午不排会」吗? [记住] [不用]`
记住→行变"已记住,可在小鹿设置查看";不用→本会话同类不再出。
红线:**看不见的记忆是监视**——一切记忆先经用户确认,永远可看可删。

### 4.6 视觉细则

- 头像统一 DeerBadge(随主题变色);🦌 emoji 只出现在文案
- 主题 accent 仅三处:勾选选中、完成点、记忆卡 💭;其余全灰阶
- 动效走 Motion token(卡片 200ms fade+6dp 上移);唯一温度动效=DeerLoading 呼吸(兼加载指示)
- 无障碍:草稿卡逐行独立焦点,读出含绝对日期;状态色文双证据

## 5. 聊天记录(§124 拍板)

现状:纯内存,杀进程即丢。设计定案:

| 决策 | 定案 | 理由 |
|---|---|---|
| 存不存 | **本地持久化**(Room 新表 ChatMessage) | 回看"上周小鹿帮我做了什么"有价值;动作卡是操作审计 |
| 上不上云 | **不上云** | 聊天是过程性数据不是用户资产(区别于日记);上云扩大隐私面,价值<风险。文案:「聊天记录只在这台手机上」 |
| 保留策略 | 滚动保留**最近 30 天且 ≤500 条**,更旧自动清 | 聊天是过程不是资产;重要产出已沉淀为日程/任务/记忆,过程可弃 |
| 会话形态 | **单一连续流,按天分段**(日期分隔头) | 手帐场景不需要多会话树(克制);历史上滑分页加载(每页 50) |
| 图片 | base64 不入库;字节落 `files/chat/` 目录,消息存文件名;清理连文件删 | 库体积 |
| 清空 | 锚定菜单「清空对话」→ 确认 → 物理删除(含图片文件) | 用户完全掌控 |
| 备份导出 | v1 不含聊天记录 | 同"过程性数据"定位 |

表结构:`ChatMessage(id, role, text, imageFile, targetKind, targetId, error, createdAt)`;
Room v10→v11 迁移;vm.chat 启动时从库载入最近一页。

## 7. 护城河判断

小鹿的竞争力不在模型多聪明(模型人人租得到),而在:
**「动作合同+真值上下文+草稿确认+同路事务+评测门禁」这套准确性工程**,
和**「藏在动作旁边」这个克制的位置感**。
前者别人抄要重写数据层;后者别人抄要放弃"AI 门面"的虚荣。
