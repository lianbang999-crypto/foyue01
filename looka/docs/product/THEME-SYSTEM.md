# Looka 主题体系规格 v1.0

> 2026-08-27 · 主题/皮肤的总设计:四层体系、生产管线、商店上架、AI 生成路线。
> 机器合同:`contracts/theme-tokens.schema.json`(16 语义槽)+ `contracts/theme-package.v1.json`(皮肤包)。
> 现状标记:✅ 已上线 · 🔜 已排期 · 💡 方向

## 0. 立场

主题是 Lifebear 验证过的价值链核心一环(个性化 = 身份与情绪价值 → 付费意愿)。
但 Looka 的主题**永远不碰可读性**:正文黑、周末红蓝、分隔线、触达尺寸不随主题变——
**皮肤换氛围,不换阅读对比度**。这条已在 Tokens 层写死(可读性槽不进包)。

## 1. 四层主题体系

| 层 | 名字 | 内容 | 获取 | 现状 |
|---|---|---|---|---|
| L0 | **九色**(品牌基线) | 一鹿九色,纯色系推导 | 永久免费 | ✅ |
| L1 | **照片主题**(个人化) | 本机取照片主色生成 16 槽包;"第十种颜色是你自己的" | 免费,照片不上传 | ✅ §123 |
| L2 | **官方皮肤包**(装扮) | 完整着せかえ:16 槽色 + 顶栏横幅画 + 底栏背景画 + 5 导航图标 + 锁屏(对齐 Lifebear Horse 形态,图 112-115) | 装扮商店:鹿角 / Pro 0🦌 永久 | 🔜 格式已冻结,渲染层未接 |
| L3 | **AI 生成主题** | 用户描述或上传图 → AI 产整套包 | Pro / 鹿角 | 💡 分两步走(§4) |

优先级(Tokens 总线已实现):**皮肤包 > 照片主题 > 九色**。
互斥规则:装 L2 卸 L1;手选九色卸一切(✅ 已实现"选九色自动卸照片")。

## 2. L2 官方皮肤包:生产管线与上架流程

```
设计资产(封面竖图 3:4 / 顶栏横幅 / 底栏背景带 / 5 导航图标 / 锁屏背景 + 16 槽色)
  → 按 theme-package.v1.json 打包(tokens 内嵌 theme-tokens 全量)
  → scripts/check_contracts.py 校验(缺槽/缺资产直接拒)
  → 资产上 R2(theme/<id>/ 前缀)
  → catalog.v1.json 加条目(id=theme:xxx, kind=theme_pack, 价格, acquire)
  → worker SHOP_ITEMS 同步(对账门禁保证一致)
  → 装扮商店可见 → 购买/领取 → entitlements 记账 → 应用
```

**工程前置(上第一个包之前必须完成):**
1. App 皮肤渲染层:顶栏横幅、底栏背景、导航图标的实际绘制(插槽格式已定义,渲染未接)
2. Web 已留 `--lk-skin-top/bottom` 插槽 + `applySkinPack()`,导航图标槽待接
3. 包的下载与缓存(R2 → 本地;离线可用;卸载即清)

**首批主题候选(与品牌资产联动):**
- 「敦煌」:与敦煌贴纸包成套(买过贴纸包的给折扣或捆绑价——💡 捆绑机制另议)
- 「四季」系列:春樱 / 夏海 / 秋枫 / 冬雪(可做季节限定运营位,但**不做倒计时焦虑促销**)
- 「小鹿的一天」:晨昏两版

定价与贴纸包同规则:30-50🦌 或 Pro 0🦌 永久领取;数字只进 catalog.v1,页面不手写。

现状 ✅:两件贴纸包、购买确认(余额 42→12)、Pro 免费领。

## 4. L3 AI 生成主题:两步走

**L3a AI 配色(先做,成本低可控):**
用户输入一句描述("像黄昏的海")或一张图 → 文本/视觉模型输出 16 槽色 JSON(按 theme-tokens 合同)
→ 本地校验(可读性槽强制回填出厂值,AI 只允许配氛围槽)→ 预览 → 应用/存为"我的主题"。
计费:2🦌(economy.v1 已有 theme:2)。与 L1 照片取色的关系:照片取色=确定性算法免费;
AI 配色=生成式付费,两者并列不互替。

**L3b AI 生成图像资产(后置,质量与成本待验证):**
横幅/底栏/图标的图像生成——需图像模型管线、风格一致性控制、审核。
💡 阶段,不写进任何用户可见文案。

**安全边界:** AI 永远不能直接产出"已应用的主题"——生成 → 本地合同校验 → 用户预览确认,
三步缺一不可(与 AI 动作草稿确认同一哲学)。

## 5. 铁律汇总

1. 可读性槽(text_primary/secondary/divider/weekend/holiday/scrim/danger)不随任何主题层变
2. 数字(价格/权益)只进 catalog.v1/economy.v1,页面不手写
3. 皮肤是边框装饰,不进内容层(月历格子区永远白底——Lifebear 图 114 实证的哲学)
4. 已购/已领永久拥有,不过期不回收
5. 不做倒计时/焦虑促销/连续签到式主题运营
6. 换主题 300ms crossfade,无爆炸式庆祝动效
