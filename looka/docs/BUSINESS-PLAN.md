## 2. 为什么是现在

### 2.1 一个被低估的品类：「手帐」

「手帐」（手账 / 手帳 / bullet journal）不是「记事本」的另一种叫法。它是一种**带审美的自我记录行为**：
贴纸、胶带、配色、排版本身就是目的的一部分。

- 实体手帐是一个成熟的消费市场（日本 Hobonichi、KOKUYO；国内文具与胶带品类）⚠️
- 中文互联网上「手帐」是一个高活跃的内容标签（小红书 / B站 / 微博）⚠️
- **但数字端几乎没有对应的中文产品** ✅（这一条我们做过竞品扫描，见第 4 章）

现有的日历/待办 App，无论国内外，几乎全是**效率工具美学**：蓝白灰、卡片、进度条、番茄钟、连续打卡天数。
它们服务的是「我要更高效」的需求。

**没有人服务「我想把日子记得好看一点」这个需求。**

### 2.2 Lifebear 已经验证了这个模型 —— 但它没出海

日本的 Lifebear（ライフベア）是这个模型最完整的验证：
日历 + 待办 + 笔记 + 日记 四合一，功能几乎全免费，**靠主题和贴纸变现**。

⚠️ 据其官方口径，累计下载超过 1000 万（**未核实，需尽调复核**）。

它留下的空白：
- ❌ **没有中文版**，没有面向中文市场运营
- ❌ **没有 AI**（产品形态定型于 AI 之前）
- ❌ **审美是日系的**，不是中文用户的文化母题

> 我们不是在赌一个没被验证的模型。**模型被验证过了，只是没人用中文做。**

### 2.3 AI 成本崩塌，让「AI 助理」第一次成为小团队能做的事

2024→2026，推理成本下降了一到两个数量级。⚠️

对我们的具体含义（这一条是我们自己算的 ✅）：
```
一次 AI 对话 ≈ 3,000 输入 + 600 输出 tokens ≈ ¥0.011
月度限额 100 次全部打满 ≈ ¥1.1 / 用户 / 月
实际使用率通常 10~20% → 约 ¥0.11~0.22 / 用户 / 月
```

**这意味着一个 ¥12/月 的订阅，AI 成本占比不到 10%。**
三年前这件事的成本结构是不成立的。

### 2.4 时机总结

```
品类空白（中文数字手帐）  ×  模型已验证（Lifebear）  ×  成本崩塌（AI）
```

三者同时成立的窗口，我们判断在 **未来 2~3 年**。之后要么被大厂顺手做掉，要么被同类占住心智。

### 3.2 差异化的三根支柱

#### 支柱一：反效率的产品哲学

```
不催你  ·  不给红色角标  ·  不做连续打卡  ·  不做排行榜
```

这不是「少做了功能」，是**主动选择的立场**。
效率类 App 用焦虑驱动留存；我们赌的是**另一批被焦虑赶走的用户**。

⚠️ 这是差异化，也是风险 —— 它天然放弃了「效率」这个更大的市场。这是清醒的取舍。

#### 支柱二：AI 生成主题（**竞争壁垒**）

计划中的核心功能（§47 已完成技术方案设计，未实施）：

```
用户传一张照片（比如一杯抹茶拿铁）
 ① 端上取色（androidx.palette）—— 图片不出设备 ✅ 隐私
 ② AI 从我们自建素材库里选配纹理 + 装饰 + 横幅
 ③ AI 起名：「森屿抹茶 · 轻手帐」
 ④ 出 3 套候选 → 一键应用（整体风格改变，不只是换主色）
```

**为什么这条抄不走**：需要「自建美术素材库 + 取色算法 + 统一调性」三者齐备。
纯代码能力抄得走，**审美体系和素材积累抄不走**。

**为什么成本可控**：AI 只输出几十字节的选配 JSON（< ¥0.001/次），
**不是让 AI 出图**（一次几毛钱，用户试 5 次就吃掉一个月订阅）。

#### 支柱三：文化根

九色鹿来自敦煌壁画《鹿王本生图》。这不是贴皮 —— 主题体系（敦煌晨光、宣纸、祥云纹）
天然有一套中文用户认得、且日系产品给不了的审美母题。

### 4.1 竞争结论

**没有一款中文产品同时具备：四合一 + 手帐美学 + 原生 AI + 云同步。**

我们最像的对手是 Lifebear —— 而它不在中文市场，且没有 AI。

### 4.2 真正的威胁排序

1. 🔴 **大厂顺手做**（小红书、豆瓣、字节做一个手帐 App）—— 但大厂难做小众审美，且这个盘子对它们太小
2. 🟡 **Lifebear 出中文版** —— 概率低（十余年未出海），但一旦发生我们的先发优势会被压缩
3. 🟡 **同赛道创业者** —— 最现实的竞争，护城河只能靠素材积累和用户情感

双档设计参考 Lifebear（基础档只去广告 / 高级档全装扮）⚠️。

### 6.2 免费与付费的分界：装扮墙

```
永远免费：全部手帐功能 · 云同步 · 数据导出 · AI 对话不限次 · 104 枚表情 · 九色主题 · 密码锁
付费解锁：AI 生成主题 · 全部纹理与装饰 · 更聪明的模型不限量 · 标签体系 · 年度回顾长图
```

**为什么不卡实用功能**：
1. 产品原则是「尽量让利于用户」—— 卡提醒、卡同步条数这类做法与之冲突
2. 卖装扮比卖功能**更真诚**，也更符合手帐用户的付费心理 ⚠️
3. 免费版足够好用 → 口碑传播 → 这是我们唯一负担得起的获客方式

⚠️ **代价要说清楚**：装扮墙需要**持续产出美术素材**（每月新主题/表情）。这是长期成本，见第 10 章风险。

### 6.3 两个承诺（写进商店文案，已上线 ✅）

- **不偷偷扣钱**：可随时取消；也提供一次性月卡/年卡，不强制自动续费
- **到期不收回**：做的主题、写的内容、导出的东西，到期后照样能用

## 7. 技术架构与单位经济（**这是下行风险最小的一环**）

### 7.1 架构

```
Android (Kotlin / Compose / Room)  ┐
网页 PWA (原生 JS)                  ├──► Cloudflare Worker ──► D1 (SQLite)
                                   ┘         │                 R2 (APK 分发)
                                             ▼
                                  OpenRouter（海外高级模型）
                                  SiliconFlow（国内 DeepSeek，双引擎自动切换）✅
```

**双 AI 引擎已上线** ✅：海外走 OpenRouter，失败自动降级到国内 SiliconFlow，
解决了「大陆用户用不上高级模型」的问题。

### 7.2 成本结构 ✅（自算，可验证）

| 项目 | 成本 | 说明 |
|---|---|---|
| Cloudflare Workers | $5/月起 | 含 1000 万请求/月 |
| D1 数据库 | 含在内 | 免费额度已够当前规模 |
| R2 存储 | ~$0 | 10GB 免费，**无出口流量费** |
| 域名 | ~¥100/年 | |
| **固定成本合计** | **约 ¥40~75/月** | **可服务上万用户** |
| AI 边际成本 | **< ¥1/用户/月** | 限额打满的极端值 |

### 7.3 单位经济

```
ARPU（付费用户）      ¥12 / 月
  − 支付通道抽成       约 5~10% ⚠️（爱发电/Ko-fi 费率需核实）
  − AI 边际成本        < ¥1
  − 存储/带宽边际      ≈ ¥0（Cloudflare 无出口费）
= 毛利                 约 ¥10 / 月  →  毛利率 > 85%
```

### 7.4 这个成本结构最重要的含义：**极长的生存期**

即使**零收入**，运营成本也只有每月几十块。
这意味着**这个项目不会因为烧完钱而死**，只会因为做不出用户喜欢的东西而慢慢停。

对投资人的含义：**下行风险极小，时间可以换空间。**
