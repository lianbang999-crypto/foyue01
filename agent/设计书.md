# 问道智能体 · 设计书

> 2026-08-04 立。目标：重做「问文库／问道」为智能体，未来整体替换 `worker/index.js` 之 `serveAsk`（现行为单线 RAG：嵌入→召回→重排→生成）。
> 借鉴同门先例：选佛谱智能体（`十法界须弥山世界/agent/`，其设计书「前车之鉴」六条与 guard／句级闸已实测有效）。

---

## 一 · 立场：骨可学，皮不可穿（2026-08-04 与发起人定）

据《大安法师答问风格研究》（820 条全量统计＋13 条细读，见 `_brain/context.md` 08-04 条）：

**可学之骨**（智能体输出的体例）：
- 直答为主、结论先行（法师 67% 开门见山下判断）；
- 判 → 理 → 据 → 归 的结构；
- 平实白话、斩截不堆辞藻；
- 宽严有度——不替法师立比他本人更严的戒条。

**不可穿之皮**（触「不扮演」红线，硬性禁止）：
- 第一人称亲历（「我们东林寺」「前几年有个居士来找我」）——编一条即妄语级幻觉；
- 对机直斥（「你这个知见就有问题」）——AI 观不了机，且是冒用师承权威；
- 法师口吻本身——**有据可查只解决内容真假，解决不了归属真假**：通篇法师口吻，读者记住的是「大安法师这么说的」，包括模型自己组织的句子。

**落法：让原话多说话。** 风格的最佳载体不是模仿，是引用——
1. **定本直出**：命中 820 问答者，原答全文直出，风格 100% 保真，天然有据；
2. **综述转述**：判断先行但**判语必须出自语料**（引文中法师下过的判，缀角标）；法师声口只在引号内，引号外是第三人称转述者；
3. **署名**：界面明示「AI 依大安法师讲记综述」；引文与转述视觉分开。

三条可校验纪律（写入 compose 系统提示与 verify 句级闸）：
- **判语有据**：答首判断句须缀角标（M1 弱校验：首句无角标记 issue；M2 升级 LLM 判语回查）；
- **禁第一人称亲历**：亲历句式（引号外）出现即丢句；
- **劝诫可转引不可自发**：「一定要／千万不要」只可在引号内或「法师劝…」转述里。

## 二 · 接口契约

**定位（发起人 2026-08-04 二定）：独立站。** 自有 API 端口公开服务，`/` 出极简问答页；
自定义域待部署验证后由发起人定（wrangler.toml 备有注释）。**知识底本＝文库全库**——
L2 综述层绑定与主站同一 Vectorize 索引（8999 块＝241 篇讲记＋820 问答），
L0 定本层只是全库之上的确定性快路，不是知识面的边界。

**请求** `POST /v1/ask`

```json
{ "q": "问题（≤300字）", "history": [{"role":"user|assistant","content":"…"}] }
```

**响应**：SSE（`event:` + `data:` 帧），为现行前端协议之**超集**——现行 `app.js` 解析器只认识 `sources`／`delta`，未知事件自动忽略，故新旧前端皆可直接消费：

| event | data | 说明 |
|---|---|---|
| `mode` | `{requestId, mode, basis:{label}, cacheStatus?}` | 新增。mode＝`dingben`｜`composite`｜`catalog`｜`care`｜`refused`｜`degraded` |
| `sources` | `[{n,title,series,path,kind,x}]` | 与现行同形（x＝160 字摘录），前端出处卡直接可用 |
| `delta` | `{text}` | 与现行同形 |
| `done` | `{evidenceStatus, verify:{kept,dropped,issues}, remaining?, cacheStatus?, timing}` | 扩展。evidenceStatus＝`grounded`｜`ungrounded`｜`refused` |

**替换路径**（二者皆可，可并存）：
- 主 worker（bojingtai）加 service binding ＋ `/api/ask` 内转 `https://ask.internal/v1/ask`——前端零改动；
- 或前端直连独立站域（`/v1/ask` 已开 foyue.org 系 CORS）——换 URL 一行。

## 三 · 知识底本分层

| 层 | 内容 | 规模 | 取法 | 过 LLM |
|---|---|---|---|---|
| **L0 定本层** | 820 条大安法师答问（问＋答＋出处） | 820 | 字二元组词法预筛 → bge-reranker 复核 → 阈值直出 | **否** |
| **L1 目录层** | 文库 38 部 241 篇＋音频 22 部＋问答总数 | 小 | 规则匹配查表 | 否 |
| **L2 讲记层** | 241 篇讲记全文切块（现有 Vectorize `foyue-wenku`，8999 块） | 8999 | 嵌入召回→重排→**据文综述**（句级闸） | 是 |
| — | 替问者作个人裁断、预测吉凶、危机求助 | — | 专路（拒答定句／关怀转介），不进生成 | 否 |

铁律承袭选佛谱：**能查表的绝不检索，能直出的绝不生成。**
注意：拒答边界要窄——感应神异／民俗／临终等「敏感题」法师大多亲答过（研究实据），能检索到亲答的照直出，检索不到的才如实说无。

## 四 · 请求处理次序

```
guard 分级（信任判据 ask.internal，同选佛谱 guard.js）
 → intent 规则路由（M1 纯规则零成本：注入→refused；危机→care；目录→catalog）
 → L0 定本词法档：Dice≥0.62 或 覆盖率≥0.92 → 原答直出（零成本，任何来源）
 → 快取（KV，键含模型+builtAt，7日）命中→回放（零成本，置于额度前）
 → 生成层（一请求一额度 take()）：rerank 复核档命中→直出；否则嵌入→召回20→重排8→纪律生成→句级闸→流式
 → 降级链：无钥／限流／检索空 → 定本近似候选摘要（degraded）→ 再不济拒答定句
```

**来源分级**（2026-08-04 二修：独立站定位，公网即正门）：
- 公网直访：生成开放，双限流（平台 ratelimit `PUB_RL` 每 IP 8/分 ＋ 隔离实例兜底）——与现行
  `/api/ask` 同水位，非新增暴露面；`PUBLIC_GEN=off` 一行应急关闸（回到零生成降级链）；
- service binding 内转（`ask.internal`）：免分钟限流内门，按 `x-ask-client` 日配额（默认 60），额满降级不拒答。

## 五 · 句级闸（verify.js）

材料干草堆＝检得段落全文。四查：
1. 角标越界 → 剥角标仍吐；
2. 直引「」≥4 字须逐字可寻 → 丢句；
3. **亲历句式**（剥引号后匹配「我们东林寺／我告诉他／我曾／我当年／有个居士…来找我」类）→ 丢句；
4. 裸数字（≥2 位）材料无 → 丢句。
done 级：首句无角标记 `verdict-uncited`（M1 非致命）；丢句过半→`ungrounded`；全篇零有效角标→`ungrounded`。

## 六 · 评测（eval/）

- `selfhit.mjs`：820 条自命中（原问→应命中自身；标题作问→模拟用户短问法），离线可跑，输出阈值标定依据；
- `cases.mjs`：意图路由／句级闸／降级链案例集，直调模块离线可跑；
- 改述题、rerank 阈值标定、综述质量：需 SF key，联网跑（M2 补齐后换模型必跑）。

## 八 · 语料解析既知之坑

- 820 条中 11 条为「大安法师：」开示体（无「答」字、无问句），问文取标题；
- 问者称谓有「问／居士／信众」三式；
- 出处行有 `----`／`——` 两式，19 条无出处行；
- 答文最长 3730 字——直出不截断，前端将来做折叠。
